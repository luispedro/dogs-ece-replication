# ECE replication

## Data

Data is available at https://zenodo.org/records/16356977. In particular, I want to analyse the extra-chromosomal elements (ECEs).

## Question

How do the ECEs replicate? Is it different between the different types of ECEs? Are there patterns in the replication mechanisms that can be identified?

## Technology

- Use pixi to install the necessary packages in a reproducible way (do not rely on the system python).
- Use jug + python + matplotlib to coordinate the analysis and generate plots.
